# Donuts App

## 🧩 Description

Donuts App is a web application built with React that allows users to explore and interact with a collection of donuts in a simple and visually appealing interface.

The project focuses on creating a clean UI and managing dynamic state to provide an engaging user experience.

## 🚀 Live Demo

https://donuts-app-chi.vercel.app/

## 🚀 Technologies

* React
* JavaScript (ES6+)
* CSS
* Vercel (deployment)

## 🎯 Features

* Interactive donut listing
* Dynamic rendering of items
* User interaction (selection / actions)
* Responsive and clean UI
* State-driven interface

## 🧠 Key Concepts

* State management with React hooks
* Conditional rendering
* Component-based architecture
* Handling user interactions
* Separation of logic and presentation

## 📦 Installation

```bash
git clone https://github.com/ChioArenillas/DonutsApp
cd DonutsApp
npm install
npm run dev
```
